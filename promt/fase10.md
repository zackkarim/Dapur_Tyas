## PHASE 10 — MANAJEMEN MEJA RESTORAN

Sekarang buat sistem manajemen meja.

Admin dapat:

* tambah meja
* edit meja
* hapus meja jika belum digunakan
* mengaktifkan/nonaktifkan meja
* melihat status meja

Data meja minimal:

* ID meja
* nomor/nama meja
* kapasitas
* status

Status meja:

* Tersedia
* Digunakan
* Menunggu Pesanan
* Selesai

Contoh:

Meja 01
Kapasitas: 4 orang
Status: Tersedia

Meja 02
Kapasitas: 2 orang
Status: Digunakan

Buat halaman admin dengan tampilan card meja yang mudah dipantau.

Jangan membuat QR code dulu.
