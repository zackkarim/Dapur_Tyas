# PHASE 07 — CATEGORY MANAGEMENT

Admin dapat mengelola kategori menu.

Kategori default:

🍛 Makanan
🥤 Minuman
🍿 Snack

Fitur:

* lihat kategori
* tambah kategori
* edit kategori
* aktif/nonaktif
* hapus jika aman

Tambahkan:

* jumlah menu per kategori
* search
* status kategori

Jika kategori sudah digunakan menu, jangan sampai penghapusan merusak data.

Gunakan soft delete/nonaktif jika diperlukan.
