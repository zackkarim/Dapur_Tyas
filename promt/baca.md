# MASTER RULE — PROJECT DAPUR TYAS

Kita sedang membangun aplikasi web kasir dan manajemen restoran bernama:

**DAPUR TYAS**
**by TECNO GARAGE**

Project ini adalah sistem POS (Point of Sale) untuk usaha yang menjual:

* Makanan
* Minuman
* Snack

## ATURAN UTAMA

1. Jangan mengerjakan fase berikutnya sebelum saya meminta.
2. Fokus hanya pada fase yang sedang saya berikan.
3. Jangan menghapus atau merusak fitur dari fase sebelumnya.
4. Sebelum mengubah file yang sudah ada, baca dan pahami kode yang sudah dibuat.
5. Gunakan struktur project yang rapi dan mudah dikembangkan.
6. Gunakan PHP + MySQL untuk backend.
7. Gunakan HTML, CSS, JavaScript untuk frontend.
8. Gunakan PDO dan prepared statement untuk database.
9. Password wajib menggunakan password_hash().
10. Semua input pengguna harus divalidasi.
11. Gunakan session untuk autentikasi.
12. Gunakan role:

* admin
* kasir

13. Admin memiliki akses penuh.
14. Kasir hanya memiliki akses transaksi dan fitur yang diperlukan kasir.
15. Jangan memberikan akses admin kepada kasir.
16. Gunakan database relasional yang rapi.
17. Jangan menggunakan data dummy sebagai data permanen.
18. Jika membutuhkan data dummy untuk testing, tandai dengan jelas.
19. UI harus responsive.
20. Jangan membuat desain norak.
21. Jangan menggunakan terlalu banyak gradient, glow, animasi, atau warna mencolok.
22. Desain harus terlihat seperti aplikasi restoran/POS profesional.
23. Gunakan desain modern, bersih, elegan, nyaman dilihat dan mudah digunakan.
24. Identitas utama adalah DAPUR TYAS.
25. "by Tecno Garage" menjadi identitas kecil/sub-brand.
26. Gunakan bahasa Indonesia untuk UI.
27. Semua nominal uang menggunakan format Rupiah.
28. Format tanggal menggunakan format Indonesia.
29. Semua transaksi harus memiliki nomor transaksi unik.
30. Jangan membuat sistem pembayaran online sungguhan tanpa konfigurasi/payment gateway yang jelas. Untuk tahap awal, pembayaran online dapat dibuat sebagai simulasi.
31. Setiap fase harus menghasilkan fitur yang bisa langsung diuji.
32. Setelah selesai, tampilkan:

* file yang dibuat
* file yang diubah
* fitur yang berhasil
* cara testing
* kemungkinan masalah

33. Jangan hanya menjelaskan. Implementasikan langsung kode yang diperlukan.
34. Jika ada masalah dengan kode fase sebelumnya, perbaiki dengan tetap menjaga fitur yang sudah ada.
35. Jangan melanjutkan ke fase berikutnya secara otomatis.

## STYLE UI

Tema restoran modern:

* warm white / cream
* charcoal
* terracotta / orange-brown
* olive green sebagai warna pendukung
* sedikit gold sebagai aksen jika diperlukan

Gunakan:

* card modern
* shadow lembut
* border radius 12–16px
* typography bersih
* icon yang konsisten
* whitespace yang cukup
* animasi kecil dan halus

Hindari:

* neon berlebihan
* gradient berlebihan
* animasi berlebihan
* tampilan seperti template gaming
* terlalu banyak warna
* layout yang penuh
