# PHASE 01 — PERENCANAAN SISTEM

Sebelum membuat kode, analisis dan rancang keseluruhan sistem Dapur Tyas by Tecno Garage.

Sistem terdiri dari 3 bagian utama:

1. ADMIN
2. KASIR
3. PELANGGAN

Alur utama:

PELANGGAN
→ Scan QR meja
→ Membuka halaman pemesanan
→ Melihat menu
→ Memilih makanan/minuman/snack
→ Checkout
→ Pesanan masuk ke kasir
→ Kasir menerima pesanan
→ Pesanan dibuat
→ Pesanan diantar
→ Pelanggan melihat status
→ Pembayaran
→ Pesanan selesai

ADMIN bertugas mengelola:

* menu
* kategori
* stok
* meja
* QR meja
* kasir
* transaksi
* pengeluaran
* laporan
* keuntungan/kerugian
* pengaturan restoran

KASIR bertugas:

* menerima pesanan pelanggan
* membuat transaksi langsung
* mengubah status pesanan
* memproses pembayaran
* mencetak struk
* melihat riwayat transaksi

PELANGGAN:

* scan QR meja
* melihat menu
* memilih menu
* membuat pesanan
* melihat nomor pesanan
* melihat status pesanan
* melihat status pembayaran

Tentukan:

1. Struktur folder.
2. Struktur halaman.
3. Struktur database.
4. Relasi database.
5. Alur setiap role.
6. Alur pesanan.
7. Alur pembayaran.
8. Alur stok.
9. Alur tracking pesanan.
10. Sistem keamanan.

Buat ERD dalam bentuk teks.

JANGAN membuat implementasi kode terlebih dahulu.

Output hanya berupa rancangan teknis.
